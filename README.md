# Ritmo

Constrúyete a tu ritmo. Alimentación, movimiento y descanso, con Blobbie a tu lado.

**[Descargar o actualizar Ritmo](https://web-black-eta-71.vercel.app/descargas.html)**

La página muestra la versión y la fecha de actualización, con los enlaces directos:

- [Android · APK](https://github.com/vrj1771-droid/ritmo-descargas/releases/latest/download/ritmo-supabase.apk)
- [Windows · ZIP](https://github.com/vrj1771-droid/ritmo-descargas/releases/latest/download/ritmo-windows.zip)
- [iPhone · IPA sin firmar](https://github.com/vrj1771-droid/ritmo-descargas/releases/latest/download/ritmo-supabase-ios.ipa)

Windows: extrae la carpeta completa y abre `Ritmo/ritmo.exe`.
iPhone: el IPA requiere firma e instalación desde una PC. También puedes
[abrir Ritmo en Safari](https://web-black-eta-71.vercel.app/) y usar Compartir →
Agregar a pantalla de inicio.

Desde 1.0.2, la app avisa cuando existe una versión posterior. La versión actual
no muestra ese aviso. Las versiones anteriores necesitan esta primera descarga manual.

[Historial y notas de las versiones](https://github.com/vrj1771-droid/ritmo-descargas/releases)
